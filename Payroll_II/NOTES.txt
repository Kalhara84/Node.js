INSTALLATION
------------
Requirements: Node.js 20+, PostgreSQL 13+

######################################################################################################
HOW THE FRONTEND PROJECT WAS CREATED  (Node.js + Vite + TypeScript)
######################################################################################################
Step 1: Install Node.js
	Download and install Node.js (https://nodejs.org/)

Step 2: Check Node.js and npm versions
	Open CMD or the VS Code terminal.
		node -v
		npm -v

Step 3: Create the project
	npm create vite@latest frontend -- --template vanilla-ts
	(This project uses plain TypeScript. For a React app use:
	   npm create vite@latest my-project -- --template react
	   npm create vite@latest frontend   -- --template react-ts )

Step 4: Go to the project folder
	cd frontend

Step 5: Install dependencies
	npm install
	npm install bootstrap bootstrap-icons

Step 6: Run the project
	npm run dev


######################################################################################################
HOW THE BACKEND PROJECT WAS CREATED  (Node.js + Express + TypeScript)
######################################################################################################
Step 1: Install Node.js and check the versions (same as above: node -v, npm -v)

Step 2: Create the backend folder
	mkdir backend
	cd backend

Step 3: Initialize the Node.js project
	npm init -y

Step 4: Install the packages
	npm install express cors pg
	npm install --save-dev typescript tsx @types/node @types/express @types/cors @types/pg
	(tsx replaces nodemon: it runs TypeScript directly and restarts on every change)

Step 5: Create tsconfig.json and the code
	npx tsc --init          (or copy backend/tsconfig.json)
	Create src/server.ts and src/app.ts. The smallest working version:

		import express from "express";
		import cors from "cors";
		const app = express();

		app.use(cors());
		app.use(express.json());

		app.get("/", (_req, res) => {
		  res.send("Payroll API is running");
		});

		const PORT = 3001;
		app.listen(PORT, () => {
		  console.log(`Server running on http://localhost:${PORT}`);
		});
